Technologies
============

Application
-----------

* **Python 3.8** : langage et version de référence du projet ;
* **Django 3.0** : framework web, ORM, routage et interface d'administration ;
* **SQLite** : base de données incluse dans le projet ;
* **HTML, CSS et JavaScript** : interface utilisateur ;
* **Bootstrap 5** : composants et mise en page côté navigateur.

Qualité et exploitation
-----------------------

* **pytest**, **pytest-django** et **pytest-cov** : tests et couverture ;
* **Flake8** : contrôle du style Python ;
* **Sentry SDK** : collecte des erreurs et des journaux de niveau ``ERROR`` ;
* **Gunicorn** et **WhiteNoise** : serveur WSGI et fichiers statiques ;
* **Docker** : image exécutable de l'application ;
* **GitHub Actions** : intégration et déploiement continus ;
* **Render** : hébergement du service web ;
* **Sphinx** et **Read the Docs** : génération et publication de cette
  documentation.
